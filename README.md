# Space Invaders

This is an exercise for me to learn a little state-machine thought. It may even
be the subject of some theory of computation stuff. I will use Claude Coding to
back this up also as an education into AI.

The sprite sheet is derived from Tomohiro Nishikado's original notebook. They
are copyrighted by Taito but I use them under the fair use clause.

The first attempt will be in Python, my work language, and then use it
as pseudo-code for other, more difficult languages.

## On Python Typing

Python is duck-typed. However, I find that the convenience can lead to
programming errors so I will use type hints.
